Support

Answers to what people ask most. Something else? Open a request and describe what happens.

Try it without a Mac

Tap “Try without a Mac” on the first screen, or Settings › Add the demo Mac. The demo Mac lives inside the app: terminal, files, Monitor and Docker all work with it, and nothing goes over the network.

Connect to your Mac

On the Mac open System Settings › General › Sharing and turn on Remote Login. In PilotDesk add a host with the Mac's address (for example MyMac.local or its IP), your Mac user name and password.

Remote desktop and extended display

Download PilotDesk Host (free, macOS 14 or later), drag it to Applications and open it: it lives in the menu bar. The first time, macOS asks to allow Screen Recording and Accessibility, which it needs to show the screen and move the pointer. Keep it open: it finds your iPhone or iPad on the same Wi-Fi, or over a USB cable, and asks for the pairing code shown on the device.

Pair with the QR code

When the phone asks for the pairing code, tap “Scan the QR code” and point the camera at the code in PilotDesk Host on the Mac. The camera is used only for this and nothing leaves the device. You can also type the 8 characters.

Use it away from home

At home the Mac finds your iPhone or iPad by itself. Away from home it can't, so PilotDesk uses a VPN that links the two: over SSH it tells the Mac where your device is, and PilotDesk Host connects back to it. The picture goes straight from the Mac to your device; the pairing code is still required.

With Tailscale (recommended, free for personal use)

  1. Install Tailscale on the Mac and on the iPhone or iPad, and sign in to both with the same account.
  2. On the Mac turn on Remote Login (System Settings › General › Sharing) and keep PilotDesk Host open.
  3. In PilotDesk add your Mac with its Tailscale address: 100.x.y.z, or its name like my-mac.tail1234.ts.net. You find it in the Tailscale menu on the Mac.
  4. Away from home, turn Tailscale on, open Desktop › Away from home and tap “Start over the VPN”. On mobile data choose the Low Latency profile.

Other ways

Any VPN works if two things are true: the phone can reach the Mac (SSH on port 22), and the Mac can reach the phone's VPN address. These do:

  • ZeroTier or NetBird: the same idea as Tailscale. Install it on both and use the Mac's address in that network.
  • WireGuard on your home router (many FRITZ!Box, UniFi, Firewalla and OpenWrt routers have it): connect the phone with the WireGuard app and use the Mac's home address, like 192.168.1.20.
  • The Mac's own VPN (Headscale, a self-hosted WireGuard server): same as above, with the Mac's address in that VPN.

What doesn't work: forwarding a port on the router or connecting over the open internet. PilotDesk only connects inside a private network, on purpose.

If it keeps loading: check that the VPN is on on both, that the Mac is awake with PilotDesk Host open and its two permissions granted, and that you can open the Mac's terminal in PilotDesk from the same place.

Linux computers and servers

Terminal, files, Monitor and Docker only need SSH: on Debian or Ubuntu run sudo apt install openssh-server, then add the computer in PilotDesk with its address, user name and password, as you would a Mac.

For its screen, download PilotDesk Host for Linux and install it with sudo apt install ./pilotdesk-host_1.0_all.deb. Then run pilotdesk-host in a terminal of your desktop session, or open PilotDesk Host from the applications menu: it shows the pairing code and a QR.

  • Wayland (GNOME, KDE): the desktop asks whether PilotDesk may share the screen. Pick the screen, turn on “Allow remote interaction” (without it you see the screen but cannot control it) and press Share.
  • Start at every login: pilotdesk-host --autostart.
  • Away from home, with Tailscale on both: start Remote Desktop on the phone, then on the computer run pilotdesk-host --connect followed by the phone's Tailscale address.

On Linux there is no extended display, and ⌘ on the phone's keyboard acts as Ctrl, so ⌘C and ⌘V copy and paste.

Windows PCs

Terminal, files, Monitor and Docker work over the SSH server that comes with Windows 10 and 11. To turn it on: Settings › System › Optional features › View features, add “OpenSSH Server”. Then, in PowerShell opened as administrator:

Start-Service sshd; Set-Service sshd -StartupType Automatic

In PilotDesk add the PC with its address (its name on the network, its IP, or its Tailscale address), your Windows user name and password. With a Microsoft account the user name is the name of your folder in C:\Users. The terminal opens PowerShell; Files starts from your user folder.

With a key instead of a password, use an Ed25519 key. For an administrator account Windows reads keys from C:\ProgramData\ssh\administrators_authorized_keys, not from your user folder.

The Mac is not found

Both devices must be on the same network, and PilotDesk must be allowed in Settings › Privacy & Security › Local Network on the iPhone or iPad. Over a USB cable no network is needed.

Purchases and codes

Terminal, files and one Mac are free. PilotDesk Pro or the single features are one-time purchases, and there is a free 24-hour trial. Bought on another device? Settings › Restore purchases. Got a code? Settings › Redeem a code.

Assistenza

Le risposte alle domande più frequenti. Altro? Apri una richiesta e descrivi cosa succede.

Provarla senza un Mac

Tocca “Prova senza un Mac” nella prima schermata, oppure Impostazioni › Aggiungi il Mac di prova. Il Mac di prova vive dentro l'app: terminale, file, Monitor e Docker funzionano, e niente passa dalla rete.

Collegarsi al tuo Mac

Sul Mac apri Impostazioni di Sistema › Generali › Condivisione e attiva Login remoto. In PilotDesk aggiungi un host con l'indirizzo del Mac (per esempio MioMac.local o il suo IP), il nome utente e la password del Mac.

Desktop remoto e schermo esteso

Scarica PilotDesk Host (gratis, macOS 14 o successivo), trascinala in Applicazioni e aprila: vive nella barra dei menu. La prima volta macOS chiede di consentire Registrazione schermo e Accessibilità, che servono per mostrare lo schermo e muovere il puntatore. Tienila aperta: trova iPhone o iPad sulla stessa rete Wi-Fi, o via cavo USB, e chiede il codice di abbinamento mostrato sul dispositivo.

Abbinare con il codice QR

Quando il telefono chiede il codice di abbinamento, tocca “Scansiona il codice QR” e inquadra il codice in PilotDesk Host sul Mac. La fotocamera serve solo a questo e niente esce dal dispositivo. Puoi anche scrivere gli 8 caratteri.

Usarla fuori casa

A casa il Mac trova da solo il tuo iPhone o iPad. Fuori casa non può, quindi PilotDesk usa una VPN che collega i due: via SSH dice al Mac dove si trova il tuo dispositivo, e PilotDesk Host si collega a lui. L'immagine va dritta dal Mac al dispositivo; il codice di abbinamento resta obbligatorio.

Con Tailscale (consigliato, gratis per uso personale)

  1. Installa Tailscale sul Mac e sull'iPhone o iPad, e accedi su entrambi con lo stesso account.
  2. Sul Mac attiva Login remoto (Impostazioni di Sistema › Generali › Condivisione) e tieni aperta PilotDesk Host.
  3. In PilotDesk aggiungi il Mac con il suo indirizzo Tailscale: 100.x.y.z, oppure il nome tipo mio-mac.tail1234.ts.net. Lo trovi nel menu di Tailscale sul Mac.
  4. Fuori casa accendi Tailscale, apri Desktop › Fuori casa e tocca “Avvia via VPN”. Con i dati mobili scegli il profilo Low Latency.

Altre strade

Va bene qualsiasi VPN, se valgono due cose: il telefono raggiunge il Mac (SSH sulla porta 22) e il Mac raggiunge l'indirizzo VPN del telefono. Funzionano:

  • ZeroTier o NetBird: la stessa idea di Tailscale. Installala su entrambi e usa l'indirizzo del Mac in quella rete.
  • WireGuard sul router di casa (molti FRITZ!Box, UniFi, Firewalla e router OpenWrt ce l'hanno): collega il telefono con l'app WireGuard e usa l'indirizzo di casa del Mac, tipo 192.168.1.20.
  • Una VPN tua (Headscale, un server WireGuard sul Mac o su un altro computer): come sopra, con l'indirizzo del Mac in quella VPN.

Cosa non funziona: aprire una porta sul router o collegarsi da internet aperta. PilotDesk si collega solo dentro una rete privata, apposta.

Se resta a caricare: controlla che la VPN sia accesa su entrambi, che il Mac sia sveglio con PilotDesk Host aperta e i due permessi concessi, e che da lì riesci ad aprire il terminale del Mac in PilotDesk.

Computer e server Linux

Terminale, file, Monitor e Docker richiedono solo SSH: su Debian o Ubuntu esegui sudo apt install openssh-server, poi aggiungi il computer in PilotDesk con indirizzo, nome utente e password, come faresti con un Mac.

Per il suo schermo scarica PilotDesk Host per Linux e installalo con sudo apt install ./pilotdesk-host_1.0_all.deb. Poi esegui pilotdesk-host in un terminale della sessione grafica, o apri PilotDesk Host dal menu delle applicazioni: mostra il codice di abbinamento e un QR.

  • Wayland (GNOME, KDE): il desktop chiede se PilotDesk può condividere lo schermo. Scegli lo schermo, attiva “Consenti interazione remota” (senza vedi lo schermo ma non puoi comandarlo) e premi Condividi.
  • Avvio a ogni accesso: pilotdesk-host --autostart.
  • Fuori casa, con Tailscale su entrambi: avvia il Desktop remoto sul telefono, poi sul computer esegui pilotdesk-host --connect seguito dall'indirizzo Tailscale del telefono.

Su Linux non c'è lo schermo esteso, e il tasto ⌘ della tastiera del telefono fa da Ctrl, quindi ⌘C e ⌘V copiano e incollano.

PC Windows

Terminale, file, Monitor e Docker funzionano con il server SSH incluso in Windows 10 e 11. Per attivarlo: Impostazioni › Sistema › Funzionalità facoltative › Visualizza funzionalità, aggiungi “Server OpenSSH”. Poi, in PowerShell aperto come amministratore:

Start-Service sshd; Set-Service sshd -StartupType Automatic

In PilotDesk aggiungi il PC con il suo indirizzo (il nome in rete, l'IP o l'indirizzo Tailscale), il nome utente e la password di Windows. Con un account Microsoft il nome utente è quello della tua cartella in C:\Users. Il terminale apre PowerShell; File parte dalla tua cartella utente.

Se usi una chiave al posto della password, usa una chiave Ed25519. Per un account amministratore Windows legge le chiavi da C:\ProgramData\ssh\administrators_authorized_keys, non dalla tua cartella utente.

Il Mac non viene trovato

I due dispositivi devono essere sulla stessa rete, e PilotDesk deve essere consentita in Impostazioni › Privacy e sicurezza › Rete locale su iPhone o iPad. Con il cavo USB la rete non serve.
